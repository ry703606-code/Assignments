Assignment 9.1 — Convert a Desktop Page into a Mobile-First Layout
Kya banana hai: Ek existing desktop-only webpage ko responsive banana hai.
Steps:

1. Week 8 ke dashboard ya photo gallery project ko open karo.
2. HTML ke <head> mein viewport meta tag verify karo.
3. Pehle mobile screen ke liye CSS likho.
4. Media queries ka use karke tablet aur desktop layouts improve karo.
5. Kam se kam 2 breakpoints add karo.
6. Chrome DevTools ke Device Mode se different screen sizes par test karo.
7. Horizontal overflow aur overlapping elements fix karo.
   Submission: Updated HTML/CSS files aur mobile, tablet aur desktop ke screenshots.
