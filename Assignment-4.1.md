Assignment 4.1 — Student Registration Form
Kya banana hai: Ek student registration form.
Required fields:

- Full Name
- Email
- Password
- Phone Number
- Age
- Submit button

1. Form ko <form> tag mein banao.
2. Har field ke liye proper <label> add karo.
3. Correct input types use karo, jaise text, email, password aur number ya suitable tel.
4. Har input ko unique id aur meaningful name do.
5. Required fields par required lagao.
6. Form ko submit button se complete karo.
