Assignment 4.1 — Student Registration Form[cite: 16]
What to build: A student registration form.[cite: 16]
Required fields:
- Full Name[cite: 16]
- Email[cite: 16]
- Password[cite: 16]
- Phone Number[cite: 16]
- Age[cite: 16]
- Submit button[cite: 16]
Steps:

1. Build the form inside a `<form>` tag.[cite: 16]
2. Add a proper `<label>` for each field.[cite: 16]
3. Use correct input types, such as text, email, password, and number or a suitable tel.[cite: 16]
4. Give each input a unique id and meaningful name.[cite: 16]
5. Add `required` on mandatory fields.[cite: 16]
6. Complete the form with a submit button.[cite: 16]
Submission: `registration.html` and a screenshot of the working form.[cite: 16]
