Assignment 8.1 — Dashboard-Style Grid Layout
Kya banana hai: CSS Grid ka use karke ek basic dashboard.
Steps:

1. Dashboard ka header banao.
2. Sidebar aur main content area banao.
3. Main content mein 3 ya 4 statistic cards add karo.
4. Outer layout ke liye display: grid use karo.
5. grid-template-columns aur grid-template-rows set karo.
6. Cards ke beech gap use karo.
7. Grid layout ko browser mein inspect karo.
   Submission: Dashboard webpage aur CSS file.
