Assignment 9.3 — Combine Flexbox and Grid Responsively
Kya banana hai: Ek landing page jisme CSS Grid aur Flexbox dono use hon.
Steps:

1. Header aur navigation bar banao.
2. Hero section mein text aur image arrange karo.
3. Features section mein 3–6 cards add karo.
4. Main section layout ke liye Grid use karo.
5. Navbar, card ke internal content ya hero alignment ke liye Flexbox use karo.
6. Mobile view mein columns ko single-column layout mein convert karo.
7. Desktop aur mobile dono par spacing aur alignment check karo.
   Submission: Complete responsive landing page, HTML/CSS files aur screenshots.
