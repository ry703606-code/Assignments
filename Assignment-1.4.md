Assignment 1.4 — Git Essentials I[cite: 4]
Task: Convert a local project into a Git repository.[cite: 4]
What to do:

1. Install Git and verify with `git --version`.[cite: 4]
2. Open the terminal in the project folder.[cite: 4]
3. Run `git init`.[cite: 4]
4. Configure your Git username and email.[cite: 4]
5. Create an HTML file.[cite: 4]
6. Use `git status`, `git add`, and `git commit`.[cite: 4]
7. Make at least 3 meaningful commits.[cite: 4]
Submission: Screenshots of the repository folder and the history of three commits.[cite: 4]
