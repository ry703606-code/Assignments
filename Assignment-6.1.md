Assignment 6.1 — Box Model Inspection
Kya banana hai: Ek webpage jisme different elements ke box models inspect aur modify karne hain.
Steps:

1. 3 cards ya boxes banao.
2. Har box mein heading aur paragraph add karo.
3. Har box par different padding, border aur margin apply karo.
4. box-sizing: content-box aur box-sizing: border-box ka difference observe karo.
5. Chrome DevTools mein box model diagram inspect karo.
6. Ek screenshot lo aur box model ke parts label karo.
   Submission: HTML, CSS aur annotated screenshot explaining content, padding, border aur margin.
