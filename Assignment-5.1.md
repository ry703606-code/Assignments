Assignment 5.1 — Convert an HTML Page into a Styled Page
Kya banana hai: Week 4 ki HTML website mein CSS add karni hai.
Steps:

1. style.css file create karo.
2. HTML mein external stylesheet link karo.
3. Body ka background, text color aur font set karo.
4. Headings, paragraphs aur links style karo.
5. Navigation links ko readable aur attractive banao.
6. Chrome DevTools se styles inspect karo.
   Submission: Original HTML page ka styled version aur CSS file.
