Assignment 6.2 — Backgrounds, Borders & Display
Kya banana hai: Ek webpage par 3 different card designs.
Steps:

1. 3 cards banao, jaise Basic, Standard aur Premium.
2. Har card mein title, description aur button add karo.
3. Background colors aur borders alag rakho.
4. border-radius se rounded corners banao.
5. display: block, inline aur inline-block ko practical examples mein demonstrate karo.
6. Width, height aur max-width set karo.
   Submission: 3 differently styled cards aur CSS file.
