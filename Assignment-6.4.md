Assignment 6.4 — Positioning Practice[cite: 29]
What to build: A webpage with a floating action button and a sticky navigation bar[cite: 29].
Steps:

1. Create a webpage with multiple scrollable sections[cite: 29].
2. Keep the navigation bar at the top using `position: sticky`[cite: 29].
3. Give a floating contact/help button `position: fixed`[cite: 29].
4. Place a badge inside a card using `position: absolute`[cite: 29].
5. Apply the appropriate `position: relative` to the parent element[cite: 29].
6. Control the order of overlapping elements using `z-index`[cite: 29].
Submission: Working webpage and a screenshot showing the sticky navbar, floating button, and positioned badge[cite: 29].
