Assignment 6.4 — Positioning Practice
Kya banana hai: Floating action button aur sticky navigation bar wali webpage.
Steps:

1. Ek webpage banao jisme multiple scrollable sections hon.
2. Navigation bar ko position: sticky se top par rakho.
3. Ek floating contact/help button ko position: fixed do.
4. Ek card ke andar badge ko position: absolute se place karo.
5. Parent element par appropriate position: relative lagao.
6. z-index se overlapping elements ka order control karo.
