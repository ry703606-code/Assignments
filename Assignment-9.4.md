Assignment 9.4 — Responsive Landing Page: Build
Kya banana hai: Diye gaye reference design ko dekhkar ek landing page ka initial version banana hai.
Steps:

1. Reference design mein colors, typography, images aur layout identify karo.
2. Project folder mein index.html, style.css aur images folder banao.
3. HTML mein semantic sections create karo.
4. Navbar, hero section, buttons aur feature cards ka structure banao.
5. CSS mein desktop layout implement karo.
6. Grid aur Flexbox ka appropriate use karo.
7. Base styling aur spacing complete karo.
8. Code ko GitHub par push karo.
   Submission: Landing page ka initial desktop version, HTML/CSS files aur GitHub link.
