Assignment 4.3 — Student Marks Table
Kya banana hai: Ek student marksheet table.
Steps:

1. Kam se kam 5 students aur 3 subjects ka data add karo.
2. Table ke liye <table>, <tr>, <th> aur <td> use karo.
3. Table ko <thead>, <tbody> aur <tfoot> mein organize karo.
4. <caption> se table ka title do.
5. Footer mein total ya average marks show karo.
6. Jahan appropriate ho, colspan ya rowspan use karo.
7. Table headers ko meaningful rakho.
   Submission: marksheet.html aur complete table ka screenshot.
