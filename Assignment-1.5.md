Assignment 1.5 — GitHub Essentials II[cite: 5]
Task: Upload a local project to GitHub.[cite: 5]

2. Create a new public repository.[cite: 5]
3. Connect the local repository to the remote repository.[cite: 5]
4. Upload files using `git push`.[cite: 5]
5. Add a new file and push the second commit.[cite: 5]
6. Verify the commit history on GitHub.[cite: 5]
