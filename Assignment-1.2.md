Assignment 1.2 — Development Environment Setup[cite: 2]
Task: Set up the web development environment on your computer.[cite: 2]
What to do:

1. Install Visual Studio Code.[cite: 2]
2. Install the LTS version of Node.js.[cite: 2]
3. Install the Live Server and Prettier extensions in VS Code.[cite: 2]
4. Create a folder named: web-development-practice.[cite: 2]
5. Create index.html, style.css, and script.js files inside the folder.[cite: 2]
6. Run the HTML file in the browser using Live Server.[cite: 2]
7. Verify the installation by running `node -v` and `npm -v` commands in the terminal.[cite: 2]
Submission: Screenshots of VS Code, Node.js version, and the running HTML page in the browser.[cite: 2]
