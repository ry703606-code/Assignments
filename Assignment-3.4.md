Assignment 3.4 — Semantic HTML & Accessibility
Kya banana hai: Ek existing div-based webpage ko semantic HTML mein convert karna hai.
Steps:

1. Page ko <header>, <nav>, <main>, <section>, <article>, <aside> aur <footer> se structure karo, jahan appropriate ho.
2. Navigation links ko <nav> mein rakho.
3. Main content ko <main> mein rakho.
4. Correct heading hierarchy use karo.
5. Images ke liye meaningful alt text add karo.
6. Check karo ki links aur page sections understandable hain.
   Submission: Updated semantic HTML page aur before/after screenshots.
