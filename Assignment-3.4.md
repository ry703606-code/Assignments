Assignment 3.4 — Semantic HTML & Accessibility[cite: 14]
What to build: Convert an existing div-based webpage into semantic HTML.[cite: 14]
Steps:

1. Structure the page using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` where appropriate.[cite: 14]
2. Keep navigation links inside `<nav>`.[cite: 14]
3. Keep the main content inside `<main>`.[cite: 14]
4. Use the correct heading hierarchy.[cite: 14]
5. Add meaningful alt text for images.[cite: 14]
6. Check that links and page sections are understandable.[cite: 14]
