Assignment 3.1 — Two-Page Website with Working Links[cite: 11]
What to build: A simple two-page website with working navigation links.[cite: 11]
Steps:

1. Create `index.html` and `about.html` files.[cite: 11]
2. Create the website name, introduction, and a navigation bar on the home page.[cite: 11]
3. Add Home and About links in the navigation.[cite: 11]
4. Connect both pages using `<a href="">`.[cite: 11]
5. Add a link to any external website as well.[cite: 11]
6. Use `target="_blank"` to open the external link in a new tab and `rel="noopener noreferrer"` for security.[cite: 11]
Submission: Both HTML files and a screenshot of the working website.[cite: 11]
