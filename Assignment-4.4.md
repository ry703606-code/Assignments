Assignment 4.4 — Metadata & Page Setup
Kya banana hai: Apne purane HTML projects ko proper metadata ke saath update karna hai.
Steps:

1. Har HTML file mein character encoding ke liye UTF-8 set karo.
2. Mobile viewport meta tag add karo.
3. Har page ka meaningful <title> likho.
4. Meta description add karo.
5. Ek favicon add karo.
6. Verify karo ki CSS link aur file paths sahi hain.
   Submission: Updated HTML files aur browser screenshot showing the favicon. Metadata code bhi submit karo.
