Assignment 3.3 — Ordered, Unordered & Nested Lists
Kya banana hai: Apne college ya course ki information wali webpage.
Steps:

1. College/course ka introduction likho.
2. Departments ya subjects ki list <ul> se banao.
3. Admission process ko <ol> se show karo.
4. Kisi subject ke topics ko nested list mein arrange karo.
5. Teachers ya courses ki details ke liye <dl>, <dt> aur <dd> use karo.
6. Headings aur sections ke through page ko organize karo.
   Submission: college-info.html file aur browser screenshot.
