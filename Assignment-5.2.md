Assignment 5.2 — CSS Selectors Practice[cite: 22]
What to build: A webpage using different CSS selectors properly[cite: 22].
Steps:

1. Create at least 5 HTML elements[cite: 22].
2. Style headings or paragraphs using an element selector[cite: 22].
3. Style multiple cards or sections using a class selector[cite: 22].
4. Style a specific section using an ID selector[cite: 22].
5. Use the universal selector `*` appropriately[cite: 22].
6. Use a grouping selector[cite: 22].
7. Create two conflicting CSS rules and observe the result of cascade and specificity[cite: 22].
Submission: HTML file, CSS file, and a short explanation of the selectors used[cite: 22].
